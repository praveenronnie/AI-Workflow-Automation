EVIDENCE:
{evidence}

Return ONLY valid JSON (no markdown, no code fences):

{{
  "value": "the mapped value, or null if no evidence",
  "confidence": 0.0-1.0,
  "reasoning": "brief explanation citing the evidence source",
  "sources": ["list of source references cited"]

Rules:
- For dropdown/radio fields with OPTIONS, select exactly ONE option value from the provided list.

- Confidence calibration:
  - 0.9-1.0 = explicit match in evidence
  - 0.7-0.89 = strong match across multiple sources
  - 0.5-0.69 = weak / single-source inference

- Match synonyms and business terminology to the field label/type/options.
- Preserve units when visible (SF, volts, tons, etc.) for text/number fields.
